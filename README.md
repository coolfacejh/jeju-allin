# 제주올인 — 여행 시간·일정 검증 개선판

React + TypeScript + Vite 기반 제주 여행 앱입니다. 현재는 상업 출시 전 검증 단계입니다.

Node.js 20.19 이상(20.x) 또는 22.12 이상이 필요합니다.

## 실행 및 검사

```sh
npm install
npm test
npm run build
npm run preview -- --host 127.0.0.1
```

Windows에서 npm 캐시 권한 오류가 있으면 `npm install --cache .npm-cache`를 사용하세요.

## 이번 변경

- 여행 시작일·이동수단·하루 활동 시간을 설정합니다. 첫날 제주 도착 이후의 확보시간과 마지막 날 제주 출발 전 확보시간을 일정에 반영합니다.
- 확보시간에는 공항 이동·렌터카 인수/반납·수속 시간을 사용자가 합쳐 입력합니다. 공항 경로를 자동 조회하는 기능은 아닙니다.
- 장소별로 직접 확인한 방문 가능 시작/마감과 체류시간을 입력할 수 있습니다. 시작 시각까지 대기하고, 마감·일정 종료 한도 초과는 경고합니다. 자정을 넘는 방문 가능 시간대는 지원하지 않습니다.
- 자동차 40km/h·도보 4km/h와 직선거리로 계산한 추정치입니다. 좌표가 없거나 대중교통·배편이 필요한 구간은 이동시간과 이후 도착시각을 미확인으로 표시합니다. 입력하지 않은 영업시간·휴무 여부도 판단하지 않습니다.
- 새 설정도 기존 날짜·순서·메모와 함께 저장·공유·가져오기가 됩니다. 이전 설정 없는 여행과 공유 링크도 계속 지원합니다.
- Vite 7.3.6, React 플러그인 5.2.0, React Router 7.18.3으로 업데이트했습니다. 설치된 의존성 검사에서 알려진 취약점은 0건입니다. 이는 전체 앱 보안 인증을 의미하지 않습니다.

- `src/lib/places.ts`: 기본 목록·관광 API 캐시·저장한 장소의 영구 스냅샷을 같은 경로로 조회합니다. 장소 ID 순서를 유지하고 중복을 제거합니다.
- `src/lib/trip.ts`: 날짜별 장소 순서, 장소 정보, 메모, 숙박 일수, 인원을 하나의 버전 2 여행으로 저장합니다. 추가·삭제나 기간 변경 시 기존 배치를 최대한 유지합니다.
- 일정 화면에서 날짜 간 이동, 같은 날짜 내 순서 변경, 500자 메모 입력을 지원합니다. 한 곳만 담아도 일정을 열 수 있습니다.
- 공유 링크는 압축된 여행 스냅샷을 담으므로 상대방의 브라우저 캐시에 의존하지 않습니다. 새 브라우저에서 날짜·순서·메모를 복원하고 내 여행으로 저장할 수 있습니다.
- 가져오기는 현재 보관함·일정을 대체합니다. 기존 장소가 있으면 화면에서 대체 여부를 확인하며 저장 실패 시 기존 값을 복구합니다.
- 샘플 업체·표시용 평점·후기를 추천 목록에서 제외했습니다. 기본 목록은 초기 수록 관광지이며 현장 검증 완료를 의미하지 않습니다. 숙소·음식점은 외부 관광 데이터에 의존합니다.
- 추천은 고정 가중치의 태그 비교입니다. AI 또는 확률로 오해할 수 있는 표현과 확인되지 않은 편의시설 보장 문구를 수정했습니다.
- 정보 출처와 API 수신 시각을 표시합니다. 수신 시각은 현장 확인일이 아닙니다.
- 외부 아이콘 글꼴이 실패해도 버튼을 가리지 않도록 처리하고, 지도 이름표는 HTML 대신 텍스트로 표시합니다.

## 바로 따라 하는 확인 예시

1. 취향을 설정하고 기본 관광지 2곳과 외부 관광 장소 1곳을 담습니다.
2. 여행 일정에서 한 장소를 3일차로 이동합니다.
3. 방문 순서를 바꾸고 `오후 1시 예약` 메모를 입력합니다.
4. 새로고침 후 날짜·순서·메모가 유지되는지 확인합니다.
5. 공유 링크를 별도 브라우저에서 열고 원본과 비교합니다.
6. `이 일정을 내 여행으로 저장`을 누른 뒤 일정 화면에서도 동일한지 확인합니다.

## 시간 설정 확인 예시

1. 2박 3일 여행의 일정 화면에서 여행 시작일을 선택합니다.
2. `활동 시간 · 항공편 전후 여유시간`을 열고 마지막 날 제주 출발을 `16:00`, 출발 전 확보시간을 `120`분으로 입력합니다.
3. 3일차의 일정 종료 한도가 `14:00`으로 표시되는지 확인합니다.
4. 체류시간을 길게 입력해 한도를 넘기면 일정 조정 경고가 표시됩니다. 날짜를 옮기거나 체류시간을 줄여 해결합니다.
5. 이동수단을 도보로 바꾸면 자동차보다 긴 이동 추정이 표시됩니다. 대중교통을 선택하면 구간별 시간 확인이 필요하다고 표시됩니다.
6. 공유 링크를 새 브라우저에서 가져온 뒤 날짜·교통수단·출발시각·체류시간 설정을 확인합니다.

## 현재 제한과 다음 작업

- GitHub–Vercel 연동으로 https://jeju-allin.vercel.app 에 배포했습니다. 파일 더블클릭 실행에서는 공유 링크 생성을 막습니다. localhost 주소는 다른 기기에 공유할 수 없습니다.
- 링크는 공유 당시의 사본입니다. 원본을 수정해도 기존 링크는 바뀌지 않습니다. 링크를 가진 사람은 장소와 메모를 읽을 수 있습니다.
- 현재 한 여행을 관리합니다. 여행당 최대 100곳, 메모당 500자, 공유 데이터 16,000자 제한이 있으며 초과하면 오류를 안내합니다. 메신저별 긴 링크 전달 제한은 별도 검증이 필요합니다.
- 계정·클라우드 동기화가 없으므로 브라우저 데이터 삭제 시 저장 내용도 지워집니다. 전체 로컬 스냅샷 정리 UI는 후속 작업입니다.
- 이전 ID 전용 링크는 모든 장소를 복원할 수 있을 때만 엽니다. 제외된 샘플이나 정보를 찾을 수 없는 장소는 새 링크가 필요합니다. 기존 보관함의 누락 ID는 안내 후 사용자가 제거할 수 있습니다.
- 실제 도로 경로·영업시간·항공편 운항·배편·실시간 요금의 자동 조회는 아직 없습니다. 사용자가 입력한 시간 제약을 적용하며 이동시간과 경비는 추정치입니다. 식사·휴식 자동 배치 및 숙소 출발/복귀 경로도 후속 작업입니다.
- 한국어·영어 전체 문구 통일, 시설별 검증 이력, 관리자 검수·문의, 다중 여행·데이터 복구는 후속 작업입니다.
- 기존 관광 프록시를 실제 호출해 HTTP 200과 장소 330개를 확인했습니다. 응답 필드에 영업시간·도로 이동시간은 없었습니다. 이 확인은 특정 시점의 연결 확인이며 개별 장소의 정확성이나 지속적인 가용성을 보장하지 않습니다.
- 실제 도로 이동시간 연동에는 별도의 길찾기 제공자 및 서버 연결이 필요합니다. [카카오모빌리티 공식 시작 가이드](https://developers.kakaomobility.com/guide/navi-api/start)에 앱 등록과 REST API 키 발급 절차가 있습니다. 비공개 키를 프런트엔드나 공유 링크에 넣지 않아야 합니다.

수정 전 소스는 `.backups/before-trip-fix`, 이번 작업 직전 소스는 `.backups/before-schedule-update`에 보관했습니다. 배포 시에는 `dist` 내용만 배포하고 백업·캐시·시험 산출물을 포함하지 마세요.

## 비짓제주 연동

- Vercel 환경변수 `VISITJEJU_API_KEY`를 서버 함수에서만 사용합니다. 브라우저·GitHub에 키를 넣지 않습니다.
- `/api/visitjeju?page=1`에서 비짓제주 국문 목록을 조회합니다. 제공되는 전체 페이지를 2개씩 요청하며 최대 100페이지 범위를 지원합니다. 이 범위를 넘으면 완전 수집으로 표시하지 않고 오류를 안내합니다.
- 서버 페이지 캐시와 브라우저 완전 목록 캐시는 24시간입니다. 페이지 실패 시 기존 목록을 보존합니다. 로컬 Vite 단독 실행은 서버 API를 제공하지 않으므로 비짓제주 실연동은 Vercel 배포에서 확인합니다.
- 명시된 관광·숙박·음식·쇼핑·축제·레포츠 분류를 수록합니다. 기타 콘텐츠는 장소로 추측하지 않고 제외합니다. 좌표 없는 장소는 목록에서 볼 수 있지만 지도 핀이 없을 수 있습니다.
- 이름·종류가 같고 좌표가 약 100m 이내인 다른 출처의 장소만 탐색 목록에서 통합합니다. 저장된 ID는 바꾸지 않으므로 기존 일정과 공유가 유지됩니다. 이름이 다른 동일 장소는 후속 검수가 필요합니다.
- 비짓제주 시설·평점·동반자 적합성을 임의로 생성하지 않습니다. 출처와 조회 시각을 표시합니다.

- 2026-09-19 실연동 검증: API 전체 5,304건/54페이지, 장소 분류 제외 108건, 장소 응답 5,196건에서 ID 중복을 정리한 고유 장소 4,767곳(관광 등 2,249 / 음식 1,666 / 숙소 852). 이는 비짓제주 내부 ID 중복 제거 후 수이며 관광공사와의 중복 통합 전 수치입니다.
- 실제 배포 Chrome에서 전체 수집·캐시·숙소 상세 출처·담기·새로고침 복원·일정 조회를 확인했습니다. 첫 목록은 종류별 12곳을 표시하고 전체 보기에서 추가 탐색합니다.
