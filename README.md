# 제주올인 · Jeju All-In

**취향에 맞는 제주 여행을 계획하고, 나와 동행자에게 필요한 접근성 조건까지 확인하는 여행 큐레이션 서비스입니다.**

핵심 사용자는 접근성 확인이 필요한 여행자와 동반자입니다. 휠체어 이용자·고령자·유아차 동반 가족뿐 아니라 일반 여행객도 장소를 탐색하고 일정을 만들 수 있습니다. 현재는 현장 검증을 보강하는 MVP 단계입니다.

- 서비스: https://jeju-allin.vercel.app/
- 팀: 제주7팀
- 문서 기준: 2026-10-04, 기능 코드 `1e45a10`까지 확인
- 추천 방식: 지역·거리·시간·장소 분류 등을 고려한 **규칙 기반 추천**. ChatGPT·Codex는 기획·개발·오류 분석·테스트에 활용했으며, 서비스가 생성형 AI를 실시간 호출하는 구조는 아닙니다.

## 사용자 흐름

**여행 날짜·필요 시설 선택 → 목록·지도에서 탐색 → 사진·접근성 근거 확인 → 장소 담기 → 스마트루트 구성 → 수정·저장·공유**

## 주요 기능

### 1. 여행 조건과 장소 탐색

- 첫 화면에서 여행 시작일·숙박 일수, 출입구 단차·경사로·휠체어 이동로·장애인 화장실·장애인 주차구역·승강기 조건을 선택합니다. 날짜 미정도 가능합니다. 인원은 일정 화면에서 조정합니다.
- 선택한 필수 시설이 **모두 자료상 확인된 장소**만 기본으로 표시합니다. 0건일 때 임의의 대체 장소를 섞지 않습니다.
- 사용자가 미확인 포함을 선택해도 시설이 없다고 확인된 자료는 제외합니다. 조건부·출처 충돌은 시설 충족으로 단정하지 않습니다.
- 종류·세부 분류·권역·관심 테마로 목록과 지도를 탐색합니다. 골프장·골프연습장·파크/미니골프 분류를 보강했으며 제주 전체 골프장 수록을 보장하지 않습니다.
- 상세 페이지에서 돌아올 때 필터·목록/지도·지도 중심/확대·더보기·스크롤 위치를 복원합니다.
- 내 스팟 추가, 장소 담기·제외, 일정에서 제외 및 직전 제외 되돌리기를 지원합니다.

### 2. 행사 날짜 필터

- 여행 날짜를 지정하면 **행사 기간과 여행 기간이 겹치는지** 검사합니다. 날짜 미정이면 한국 날짜 기준 오늘 이후까지 진행되는 행사를 표시합니다.
- 행사로 판별된 자료에 시작일·종료일이 없으면 제외합니다. 제목에 적힌 연도나 데이터 수신일로 개최일을 만들어내지 않습니다.
- 큐레이션뿐 아니라 보관함 표시·일정 생성에서도 같은 날짜 기준을 적용해 예전에 담은 지난 행사가 다시 추천되지 않게 합니다. 저장 ID를 임의로 삭제하는 기능은 아닙니다.
- 여행 날짜를 과거로 지정한 경우에는 그 선택 기간과 겹치는 행사가 표시될 수 있습니다. 제공처가 행사로 분류하지 않았거나 날짜가 잘못된 자료는 추가 검수가 필요합니다.

### 3. 접근성 근거와 픽토그램

- 시설별 있음·없음·조건부·정보 없음·출처 충돌을 구분하고 원문 근거를 제공합니다. **정보 없음은 시설 없음과 다릅니다.**
- 공식 관광정보·사용자 입력·추정값을 구분하며, 데이터 수신일을 현장 확인일로 표현하지 않습니다.
- 장소 상세에 항목별 픽토그램을 표시합니다. 아이콘 자체는 확인 항목을 뜻하며 시설 유무는 옆의 상태와 설명을 함께 읽어야 합니다.
- `/access-guide`에서 이지제주 픽토그램 37종과 뜻을 확인합니다. 출입구·경사로·이동로 일부 아이콘은 자체 항목 아이콘입니다.
- 이지제주 픽토그램 활용은 이지제주의 장소별 현장 조사 API 연동이나 시설 등급 인증을 의미하지 않습니다. 단차·경사로 정보만으로 독립 접근 또는 상·중·하 등급을 추정하지 않습니다.

### 4. 장소 사진과 상세 화면

- 비짓제주 대표 사진은 썸네일보다 원본 경로를 우선합니다. 상세 사진은 원본 비율을 유지하며 추가 사진 선택·원본 링크·출처를 제공합니다.
- `/api/place-photos`는 검증된 비짓제주 콘텐츠 ID로 공식 소개 사진을 최대 20장 조회합니다. 리뷰·관련 장소·다른 호스트 이미지는 제외합니다.
- 사진 순서는 공식 소개 순서를 사용합니다. AI가 사진의 대표성을 평가하거나 장소 사진을 생성하지 않습니다.
- 추가 사진이 없는 장소는 기존 대표 사진과 공식 소개 링크를 유지합니다. 모든 장소에 여러 사진이 있다는 뜻은 아닙니다.
- 화면 아래에서도 목록 복귀와 담기를 할 수 있도록 고정 버튼을 제공합니다.

### 5. 스마트루트와 일정 편집

- 장소를 가까운 권역별로 날짜에 나누고, 점심 12~14시·저녁 18~20시를 고려합니다. 카페·찻집은 식사와 구분합니다. 시간 순서가 지나친 우회를 만들면 이동 부담도 고려합니다.
- 숙소는 해당 날짜 마지막에 배치합니다. **바로 전날의 마지막 숙소가 다음 날 출발점 1번**으로 표시되고, 첫 방문지는 2번부터 이어집니다. 지도 번호와 첫 이동 구간 추정도 연결합니다.
- 출발용 숙소를 중복 방문으로 저장하거나 체크인 시간을 다시 더하지 않습니다. 연박 예약을 추론하거나 같은 숙소를 모든 날짜에 자동 복제하지 않습니다.
- 권역별 날짜 재추천·되돌리기와 현재 날짜 안에서 순서 재추천을 지원합니다. 날짜·순서·메모·방문 가능 시간·체류시간을 직접 수정할 수 있습니다.
- 여행 시작일, 이동수단, 하루 활동 시간, 첫날 도착·마지막 날 출발 전후 확보시간을 반영합니다. 확보시간은 공항 이동·렌터카·수속 등을 사용자가 합쳐 입력합니다.
- 방문 가능 시작 시각까지 대기하며 마감·하루 종료 한도 초과는 경고합니다. 인접 날짜에 여유가 있을 때 일부 초과 일정을 분산하지만, 모든 일정의 실행 가능성을 보장하지 않습니다.
- 이동시간은 자동차 40km/h·도보 4km/h와 직선거리 기반 추정입니다. 좌표 누락·대중교통·배편 등 불명확한 구간은 시간을 미확인으로 표시합니다.
- 실제 도로·교통상황·영업시간·휴무·예약 가능 여부·실시간 요금 자동 검증은 없습니다. 자정을 넘는 방문 가능 시간대는 지원하지 않습니다.

### 6. 지도와 올레길

- Leaflet + MapLibre GL + OpenFreeMap 벡터 지도를 사용합니다. 장치 해상도에 맞춰 그리며 최대 19단계 확대를 지원합니다. 큐레이션의 휠 확대는 0.25단위로 완만하게 조정했습니다.
- 클러스터·이름표·팝업·내 스팟과 지도 위치 저장을 지원합니다. WebGL·네트워크·제공처 연결 실패는 안내합니다.
- 일정 지도의 점선은 **장소 간 직선 방문 순서**입니다. 실제 도로 길찾기나 무장애 이동 경로가 아닙니다.
- 올레길 전용 섹션은 27개 코스를 A/B 분기로 나눈 29개 경로의 거리·공식 시간·난이도·출발/도착·공식 링크를 제공합니다.
- 공식 휠체어 안내 구간 10개를 별도로 살펴보고 계획 시간을 입력해 일정에 담을 수 있습니다. 일부 구간 안내를 전체 코스 접근성으로 확대하지 않습니다.
- 올레 정보는 수록 자료 기준이며 실시간 통제·우회·현장 시설 상태는 공식 공지를 추가 확인해야 합니다.

### 7. 주변 공중화장실

- 제주시·서귀포시 공식 자료를 함께 보관하며, 선택 장소 중심 **3·5·10km 내 좌표가 유효한 시설만** 직선거리순으로 표시합니다.
- 서귀포시만 따로 펼치는 주소 목록은 제거했습니다. 현재 수록 서귀포 원본은 좌표가 없으므로 반경 검색에 나타나지 않습니다. 지역을 제외한 것이 아니라 거리 계산 근거가 없는 자료를 가까운 시설로 표시하지 않는 것입니다.
- 장애인용 변기 등록 여부, 기저귀교환대, 개방시간, 출처·기준일, 전화·지도 링크를 자료 범위에서 제공합니다. 장애인용 변기 등록이 출입구나 전체 이동로의 접근성을 보장하지는 않습니다.
- 공중화장실은 배포 시점 스냅샷이며 페이지마다 원본을 다운로드하지 않습니다. 이지제주 현장 조사 연결 배열은 현재 비어 있습니다.
- 갱신: 공식 원본을 받아 `python scripts/import-restrooms.py <제주시.csv>` 또는 `python scripts/import-seogwipo-restrooms.py <서귀포.xlsx>` 실행 후 자료 검토·검사·배포합니다. 엑셀 가져오기에는 Python `openpyxl`이 필요합니다.

### 8. 한국어·영어

- KO/EN 전환을 메뉴·버튼·조건·일정·상세 안내 등에 연결하고 선택 언어를 저장합니다. 날짜·필터·담은 장소와 일정은 유지합니다.
- 비짓제주의 같은 콘텐츠 ID에 공식 영문이 있으면 장소명·주소·소개·태그를 연결합니다. 목록·상세·보관함·일정·공유 화면에서 지원하며 한국어 이름·주소와 원문 확인도 제공합니다.
- `/api/place-english`는 허용한 공식 호스트와 콘텐츠 ID만 사용하고, 해당 ID와 영문 언어 표시가 일치하는 자료만 채택합니다. 출처와 조회 시점을 표시합니다.
- 보이는 장소부터 조회하고 동시 요청은 2개로 제한합니다. 같은 ID의 중복 요청을 합치고, 영문 있음은 24시간·없음은 1시간 캐시합니다.
- **추가 번역 API 키 없이 가능한 공식 영문 연결입니다. 100% 자동 번역은 아닙니다.** 공식 영문이 없는 설명·일부 한국어 태그·시설 원문·화장실 명칭·지도 고유명은 한국어로 남을 수 있습니다.
- 접근성 원문 번역 여부가 시설의 있음/없음 판정을 바꾸지 않도록 분리했습니다. DeepL 등 자동 번역 서비스는 현재 연결하지 않았습니다.

### 9. 저장·공유

- LocalStorage의 버전 2 여행 데이터로 날짜·순서·장소 스냅샷·메모·인원·시간 설정을 보존합니다. 외부 API 캐시가 만료되어도 담은 장소 정보를 유지합니다.
- 공유 링크는 압축된 여행 사본입니다. 별도 브라우저에서 복원하고 내 여행으로 가져올 수 있습니다. 가져오기는 현재 여행을 대체하며 확인·저장 실패 복구를 지원합니다.
- 공유 후 원본을 수정해도 이전 링크는 바뀌지 않습니다. 링크를 가진 사람은 장소와 메모를 읽을 수 있습니다. 공유된 접근성 정보는 현장 검증 근거로 취급하지 않습니다.
- 현재 한 여행을 관리하며 여행당 최대 100곳, 메모당 500자, 공유 데이터 16,000자 제한이 있습니다. 로그인·계정 동기화는 없으며 브라우저 데이터 삭제 시 저장 내용도 지워집니다.

## 데이터 수집·갱신과 신뢰도

| 자료 | 수집·재사용 방식 | 주의사항 |
| --- | --- | --- |
| 한국관광공사 TourAPI | 기존 Supabase Edge Function 프록시, 확대된 페이지 범위, 24시간 캐시 | 키는 서버에 보관. 제주 전체 자료의 완전 수집을 보장하지 않음 |
| 비짓제주 목록 | Vercel 서버 함수, 페이지를 2개씩 요청하며 순차 표시 | 완전 목록 24시간 재사용. 최대 7일 기존 목록은 갱신 중 임시 표시. 실패·부분 응답으로 기존 완전 목록을 덮어쓰지 않음 |
| 비짓제주 사진 | 상세에서 필요 시 조회, 서버 24시간·브라우저 1시간 캐시 | 공식 페이지 구조·사진 제공 범위에 영향받음 |
| 비짓제주 공식 영문 | 필요 시 같은 콘텐츠 ID 조회, 서버·앱 캐시 | 공식 영문 제공 범위만 지원. 자동 번역이나 현장 검수 아님 |
| 올레·공중화장실 | 수록된 공식 자료 스냅샷 | 기준일 이후 변경은 별도 재수집·검토 필요 |

이름·종류와 가까운 좌표를 근거로 다른 출처의 중복 장소를 보수적으로 통합합니다. 출처별 건수를 더해 고유 장소 수나 접근성 검증 건수로 설명하지 않습니다. 표시용 평점·후기·샘플 업체는 추천 자료에서 제외했습니다.

## 로컬 실행과 배포

Node.js 20.19 이상(20.x) 또는 22.12 이상이 필요합니다.

```sh
npm ci
npm test
npm run build
npm run preview -- --host 127.0.0.1
```

개발 서버는 `npm run dev`입니다. Windows npm 캐시 권한 오류는 `npm ci --cache .npm-cache`로 별도 캐시를 사용할 수 있습니다. 지도 worker는 dev/build 시작 시 자동 생성됩니다.

Vite의 dev/preview만으로 `api/` 서버 함수가 실행되지는 않습니다. 비짓제주 목록·사진·공식 영문 실연동은 Vercel 환경에서 확인하세요.

| 서버 설정 | 용도 |
| --- | --- |
| `VISITJEJU_API_KEY` | Vercel 환경변수에 등록하는 비짓제주 목록 조회 키 |
| TourAPI 프록시 | 기존 Supabase 함수·서버 키 설정을 별도로 관리. 프록시를 바꾸면 `src/lib/live.ts`의 연결 설정도 확인 |
| 사진·공식 영문 | 별도의 번역 키 없이 고정된 비짓제주 공식 페이지 조회 |

환경변수 변경 후에는 다시 배포해야 합니다. API 비밀 키를 소스·README·브라우저·공유 링크에 넣지 마세요. Vercel에는 프런트엔드 빌드와 `api/` 함수가 함께 필요하며 `dist`만 정적 호스팅하면 이 함수들은 동작하지 않습니다. 백업·캐시·시험 산출물은 공개 배포 대상에서 제외합니다.

## 검증과 직접 따라 하는 예시

2026-10-04 `npm test` 재실행: **핵심 51개 + 서버 10개, 총 61개 통과**. 접근성 필터, 행사 날짜, 저장·공유, 일정 제약, 숙소 연결, 사진 추출, 공식 영문 ID 일치·캐시 등을 포함합니다. 기능 검사이며 당사자 현장 검증이나 대규모 사용자 조사 결과는 아닙니다.

브라우저 검사는 설치된 Playwright `index.mjs` 경로와 Chrome 실행 파일 경로를 설정한 뒤, 먼저 `npm run build`를 실행합니다. 예를 들어 PowerShell에서는 다음과 같이 실행합니다.

```powershell
$env:PLAYWRIGHT_MODULE = 'C:\path\to\playwright\index.mjs'
$env:CHROME_PATH = 'C:\Program Files\Google\Chrome\Application\chrome.exe'
node scripts/browser-check.mjs
node scripts/explore-check.mjs
node scripts/onboarding-events-check.mjs
node scripts/language-check.mjs
node scripts/official-english-check.mjs
```

그 밖에 접근성·갤러리·지도·올레·화장실·권역별 일정 검사 스크립트가 `scripts/`에 있습니다. 일부는 통제된 관광 API 응답을 사용하므로 실행 성공이 실제 제공처의 가용성·현장 정확성을 보장하지 않습니다. 오래된 UI 전용 스크립트는 현재 화면과의 호환 확인이 필요하며 모든 스크립트를 최신 화면에서 재실행했다는 뜻은 아닙니다.

1. 첫 화면에서 날짜와 장애인 주차구역·승강기를 선택합니다. 목록과 지도에 적용된 조건을 확인하고, 0건이면 조건을 직접 조정합니다.
2. 장소 상세를 열어 시설별 근거와 사진을 확인하고 담습니다. 아래의 목록 복귀 버튼으로 돌아와 지도·필터 위치가 유지되는지 확인합니다.
3. 1박 2일 일정에 숙소를 넣고 첫날 마지막인지, 다음 날 첫 출발점인지 확인합니다. 첫 이동시간은 추정값입니다.
4. 여행 기간에 맞지 않는 행사가 목록·보관함·추천 일정에 나타나지 않는지 확인합니다. 날짜 미정일 때는 종료 행사를 제외합니다.
5. 순서를 바꾸고 `오후 1시 예약` 메모를 입력합니다. 새로고침 후 공유 링크를 별도 브라우저에서 열어 날짜·순서·메모를 비교합니다.
6. EN으로 전환하고 공식 영문이 있는 비짓제주 장소의 소개·원문·출처를 확인합니다. 영문이 없는 장소는 한국어가 남는지 확인합니다.

## 현재 한계와 다음 과제

- 실제 도로·교통상황·영업시간·휴무·예약·시설 이용 가능성의 자동 검증은 미구현입니다. 직선 동선과 추정시간을 무장애 길찾기로 표현하지 않습니다.
- 관광약자 당사자 사용성 테스트와 대표 장소 현장 확인, 시설별 검증 이력·제보 검수 체계를 보강해야 합니다.
- 서귀포 등 좌표 미확인 화장실의 검증된 좌표 확보, 관광정보의 최신성·중복·누락 검수는 후속 작업입니다.
