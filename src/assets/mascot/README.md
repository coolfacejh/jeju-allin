# 올인 캐릭터 자산

사용자가 제공한 캐릭터 턴어라운드를 참고하여 image_gen으로 제작했습니다. 원본 수채화 디자인을 유지하고 배경이 투명한 단독 캐릭터로 생성했습니다. 표시용 WebP는 비율을 유지한 560px 변환본입니다.

- welcome: 밝은 미소, 한 손을 흔드는 환영 포즈. 첫 화면, 저장 성공, 일정 초안 안내.
- calm: 작은 미소, 고개를 살짝 기울이고 가방 끈을 잡은 차분한 포즈. 빈 결과와 빈 보관함.

공통 생성 지시: Preserve the supplied character identity, watercolor green leaf hat and floppy leafy ears, cream face and belly, pink cheeks, brown backpack and white flower scarf. One full-body character, transparent alpha background, centered with padding, no text or additional props.

화면에서는 장식 이미지로 처리하고 안내 문구를 별도의 접근 가능한 텍스트로 제공합니다. 자동 애니메이션은 사용하지 않습니다.
